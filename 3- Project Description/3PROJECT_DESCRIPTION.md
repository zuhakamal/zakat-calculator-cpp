# Project Description

The objective of this project is to develop a Zakat Calculator using C++.

Many people do not know how much Zakat they must pay on their wealth. This program helps users calculate Zakat on different categories including:

- Money
- Fruits
- Gold
- Silver
- Land

The user enters the required information and the program calculates the applicable Zakat amount according to predefined formulas.

The project was developed as part of the Programming Fundamentals course.
