# Zakat Calculator (C++)

## Overview

This project is a console-based Zakat Calculator developed in C++. It helps users calculate Zakat on different types of wealth according to basic Islamic principles.

The calculator allows users to calculate Zakat on:

- Money
- Fruits
- Gold
- Silver
- Land

---

## Features

- User-friendly console interface
- Personal information collection
- Menu-driven system
- Zakat calculation using switch statements
- Uses loops and conditional statements
- Feedback collection from users

---

## Zakat Formulas Used

### Money
Zakat = Money × 2.5%

### Fruits
Zakat = (Selling Price − Expenses) × 2.5%

### Gold
If Gold ≥ 85 grams

Zakat = Gold Value × 2.5%

### Silver
If Silver ≥ Nisab

Zakat = Silver Value × 2.5%

### Land
Zakat = Land Value × 2.5%
